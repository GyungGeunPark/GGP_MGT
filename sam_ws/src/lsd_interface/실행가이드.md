## 1. 시스템 아키텍처

```
┌─────────────────────────────┐          ROS2 Topic          ┌──────────────────────────────┐
│         로봇 PC              │  ◄──── perc/lds ────►       │         서버 PC               │
│                             │     (std_msgs/String)        │                              │
│  ┌───────────────────────┐  │                              │  ┌────────────────────────┐  │
│  │ lsd_interface/main.py │  │  cmd: 명령 (서버→로봇)       │  │  mainwindow.py          │  │
│  │ (LDS ROS2 노드)       │  │  type: 응답 (로봇→서버)      │  │  (Flask 웹 인터페이스)   │  │
│  │                       │  │                              │  │                        │  │
│  │  ┌─────────────────┐  │  │                              │  │  ┌──────────────────┐  │  │
│  │  │lds_controller.py│  │  │                              │  │  │ 웹 브라우저 접속   │  │  │
│  │  │(시리얼 드라이버) │  │  │                              │  │  │ http://<IP>:5030  │  │  │
│  │  └───────┬─────────┘  │  │                              │  │  └──────────────────┘  │  │
│  └──────────┼────────────┘  │                              │  └────────────────────────┘  │
│             │ USB-Serial     │                              │                              │
│       ┌─────┴─────┐         │                              │  + 카메라 스트리밍             │
│       │ JRT U81   │         │                              │  + 라이다 PCL 수집             │
│       │ LDS 센서  │         │                              │  + 커버 제어                   │
│       └───────────┘         │                              │  + LDS 원격 제어               │
└─────────────────────────────┘                              └──────────────────────────────┘
```

**핵심 변경 사항** (기존 대비):
- 기존: FastAPI 웹서버가 로봇 PC에서 UI + 센서 제어를 모두 담당
- 변경: 로봇 PC는 **센서 제어만** 담당, 서버 PC의 `mainwindow.py`에서 **UI 및 원격 제어**
- 통신: **단일 ROS2 토픽 `perc/lds`** (std_msgs/String, JSON 인코딩)

## 2. 사전 준비

### 2.1 ROS2 환경

두 PC 모두 동일 ROS2 도메인에 있어야 합니다.

```bash
# 두 PC에서 동일하게 설정 (기본값 0)
export ROS_DOMAIN_ID=0

# 네트워크 확인 — 서로 ping 가능해야 함
ping <상대방_IP>
```

### 2.2 로봇 PC — USB 장치 확인

```bash
# USB-Serial 장치 확인
lsusb | grep 1a86
# 기대: ID 1a86:7523 QinHeng Electronics HL-340 USB-Serial adapter

ls -la /dev/ttyUSB*
# 기대: /dev/ttyUSB0
```

> **Docker 환경 시**: `docker run --device /dev/ttyUSB0 --privileged ...` 필수

### 2.3 의존성 설치

```bash
# 로봇 PC
cd ~/sam_ws/src/lsd_interface
pip install pyserial

# 서버 PC
cd ~/sam_ws
pip install flask
```

## 3. 로봇 PC 실행

### 3.1 LDS 제어 노드 실행

```bash
# ROS2 환경 소싱
source /opt/ros/<distro>/setup.bash
source ~/sam_ws/install/setup.bash  # colcon 빌드가 있는 경우

# LDS 노드 실행
cd ~/sam_ws/src/lsd_interface
python3 main.py
```

정상 시작 시 출력:

```
HH:MM:SS [INFO] lds_controller: 포트 열림: /dev/ttyUSB0 @ 19200 bps
HH:MM:SS [INFO] lds_controller: 자동 보레이트 감지 성공 (시도 1)
[INFO] [lds_controller_node]: LDS 센서 연결 완료
[INFO] [lds_controller_node]: LDS 제어 노드 시작 — perc/lds 토픽 사용
```

### 3.2 카메라 노드 실행 (별도 터미널)

```bash
source /opt/ros/<distro>/setup.bash
source ~/sam_ws/install/setup.bash

# colcon 빌드 후 실행
ros2 run sensor_cam_mini camera_node
```

### 3.3 토픽 확인

```bash

ros2 topic list | grep lds
# 기대 출력: /perc/lds

# 토픽 메시지 실시간 모니터링
ros2 topic echo /perc/lds
```

## 5. 통신 프로토콜 (perc/lds)

단일 토픽 `perc/lds`에서 `std_msgs/String` (JSON) 으로 양방향 통신합니다.

### 5.1 명령 메시지 (서버 → 로봇)

`cmd` 필드가 있는 메시지:

| 명령 | JSON | 설명 |
|------|------|------|
| 레이저 ON | `{"cmd": "power_on"}` | 레이저 활성화 |
| 레이저 OFF | `{"cmd": "power_off"}` | 레이저 비활성화 + 연속 중지 |
| 순간 측정 | `{"cmd": "measure_once"}` | 1회 측정 |
| 연속 시작 | `{"cmd": "continuous_on"}` | 연속 측정 시작 |
| 연속 중지 | `{"cmd": "continuous_off"}` | 연속 측정 중지 |
| 모드 변경 | `{"cmd": "set_mode", "mode": "slow"}` | slow / auto / fast |
| 전압 읽기 | `{"cmd": "read_voltage"}` | 공급 전압 확인 |

### 5.2 응답 메시지 (로봇 → 서버)

`type` 필드가 있는 메시지:

| 타입 | 예시 | 발행 시점 |
|------|------|----------|
| `status` | `{"type":"status", "connected":true, "powered":true, "continuous":false, "measure_mode":"slow", "voltage_mv":3300}` | 2초 주기 자동 + 상태 변경 직후 |
| `ack` | `{"type":"ack", "cmd":"power_on", "success":true, "message":"레이저 ON 완료"}` | 명령 처리 완료 시 |
| `distance` | `{"type":"distance", "success":true, "mm":1519, "m":1.519, "signal_quality":315, "timestamp":1710000000.0}` | 측정 결과 (순간/연속) |
| `voltage` | `{"type":"voltage", "success":true, "voltage_v":3.300, "voltage_mv":3300, "message":"3.300 V"}` | 전압 읽기 응답 |
| `error` | `{"type":"error", "message":"센서가 연결되어 있지 않습니다."}` | 오류 발생 시 |

### 5.3 메시지 구분 규칙

- **`cmd` 필드만 있음** → 명령 (로봇 노드가 처리)
- **`type` 필드만 있음** → 응답 (서버 인터페이스가 처리)
- 각 측은 자기가 보낸 메시지를 무시합니다

## 6. 웹 UI 사용법

서버 PC 웹 인터페이스의 LDS 섹션:

```
┌──────────────────────────────────────────────────────────────────┐
│  LDS 레이저 거리 센서 (JRT U81)                                   │
│                                                                  │
│  ● LDS 연결됨              3.300 V     │  전원 제어               │
│  [레이저 ON]  [연속 OFF]               │  [레이저 ON] [레이저 OFF] │
│                                        │                         │
│         ┌──────────────┐               │  측정 제어               │
│         │  1 519 mm    │               │  [순간 측정] [연속 시작]  │
│         │   1.519 m    │               │                         │
│         │  SQ: 315     │               │  측정 모드               │
│         └──────────────┘               │  [Slow] [Auto] [Fast]   │
│                                        │                         │
│                                        │  최근 측정 이력  3건     │
│                                        │  14:23:01  1519mm  ...  │
│                                        │  14:23:03  1520mm  ...  │
└──────────────────────────────────────────────────────────────────┘
```

### 6.1 올바른 사용 순서

```
1. 로봇 PC에서 LDS 노드 실행 확인
        ↓
2. 서버 PC 웹에서 LDS 섹션의 "● LDS 연결됨" 확인
        ↓
3. [레이저 ON] 클릭
        ↓ (약 400ms 안정화 대기)
4. [순간 측정] 또는 [연속 시작] 클릭
        ↓
5. 거리값 확인 (mm 단위, 실시간 업데이트)
        ↓
6. [연속 중지] (연속 측정 시)
        ↓
7. [레이저 OFF] 클릭
```

### 6.2 신호품질 해석

| SQ 범위 | 의미 |
|---------|------|
| < 100 | 우수 — 최상의 신호 |
| 100 ~ 499 | 양호 — 정상 |
| 500 ~ 999 | 보통 — 타겟 반사율 낮음 |
| ≥ 1000 | 불량 — 측정 오류 가능 |

## 7. 측정 모드 선택

| 모드 | 타임아웃 | 권장 환경 |
|------|---------|----------|
| **Slow** | 8초/회 | 원거리(5~20m), 저반사 표면, 어두운 환경 |
| **Auto** | 5초/회 | 일반 실내/실외 (균형 모드) |
| **Fast** | 3초/회 | 근거리(0~3m), 고반사 표면, 빠른 응답 필요 |

> **기본값**: `slow` 모드. 최대 측정거리(20m)를 위한 최적 설정입니다.

### 0x0008 오류 자동 폴백

Auto/Fast 모드에서 `레이저 신호 너무 약함(0x0008)` 오류 시, 순간 측정은 자동으로 Slow 모드로 재측정합니다.

> 모드 변경은 연속 측정 중에는 불가능합니다. 연속 중지 후 변경하세요.

## 8. 센서 통신 단독 테스트

서버/ROS2 없이 로봇 PC에서 센서 직접 테스트:

```bash
cd ~/sam_ws/src/lsd_interface
python3 - <<'EOF'
import serial, time, struct

PORT = '/dev/ttyUSB0'
BAUD = 19200

LASER_ON     = bytes([0xAA, 0x00, 0x01, 0xBE, 0x00, 0x01, 0x00, 0x01, 0xC1])
LASER_OFF    = bytes([0xAA, 0x00, 0x01, 0xBE, 0x00, 0x01, 0x00, 0x00, 0xC0])
MEASURE_ONCE = bytes([0xAA, 0x00, 0x00, 0x20, 0x00, 0x01, 0x00, 0x01, 0x22])

with serial.Serial(PORT, BAUD, timeout=0.1) as ser:
    # 시작 시퀀스
    ser.setRTS(True);  ser.setDTR(True)
    time.sleep(0.15)
    ser.setRTS(False); ser.setDTR(False)
    time.sleep(0.5)
    ser.reset_input_buffer()

    # 자동 보레이트 감지
    ser.write(b'\x55')
    time.sleep(0.3)
    resp = ser.read(ser.in_waiting or 1)
    print(f"[0x55] 응답: {resp.hex()} -> {'OK' if resp == b'\\x00' else 'FAIL'}")

    # 레이저 ON
    ser.reset_input_buffer()
    ser.write(LASER_ON)
    time.sleep(0.5)
    r = ser.read(9)
    print(f"[레이저 ON] {r.hex()}")
    time.sleep(0.4)

    # 1회 측정 (Slow)
    ser.reset_input_buffer()
    ser.write(MEASURE_ONCE)
    buf, deadline = b'', time.time() + 8
    while len(buf) < 13 and time.time() < deadline:
        buf += ser.read(13 - len(buf))
    print(f"[측정] {buf.hex()}")
    if len(buf) >= 12:
        mm = struct.unpack('>I', buf[6:10])[0]
        sq = struct.unpack('>H', buf[10:12])[0]
        print(f"  -> 거리: {mm} mm  신호품질: {sq}")

    # 레이저 OFF
    ser.reset_input_buffer()
    ser.write(LASER_OFF)
    time.sleep(0.5)
    r = ser.read(9)
    print(f"[레이저 OFF] {r.hex()}")

print("테스트 완료")
EOF
```

## 9. 트러블슈팅

### LDS 연결 안됨 (웹 UI에서 "LDS 연결 안됨")

| 확인 항목 | 조치 |
|----------|------|
| 로봇 PC에서 LDS 노드 실행 여부 | `ros2 node list` 로 `lds_controller_node` 확인 |
| ROS2 네트워크 | `ROS_DOMAIN_ID` 동일한지 확인 |
| 토픽 통신 | `ros2 topic echo /perc/lds` 로 메시지 수신 확인 |
| 방화벽 | DDS 포트 (7400-7500 UDP) 열려있는지 확인 |

### 자동 보레이트 감지 실패

| 확인 항목 | 조치 |
|----------|------|
| RTS/DTR 제어 권한 | Docker: `--privileged` 옵션 추가 |
| 포트 번호 | `ls /dev/ttyUSB*` 로 실제 포트 확인 |
| USB 케이블 | 데이터 지원 케이블인지 확인 (충전 전용 불가) |
| 모듈 전원 | USB 인터페이스 보드 LED 점등 확인 |

### USB 재연결 후 포트 번호 변경

```bash
# dmesg로 새 포트 번호 확인
dmesg | grep -E 'ch34|ttyUSB' | tail -5

# main.py 포트 수정
# LDSController(port='/dev/ttyUSB1', ...)
```

### 측정 타임아웃

- 타겟 물체가 0.03 ~ 20m 범위 안에 있는지 확인
- 레이저가 반사될 수 있는 표면에 조준
- 강한 햇빛이나 역광 환경 피하기
- 거리 2~3m 이상에서 신호 약함 오류 → Slow 모드로 전환

### 포트 사용 중

```bash
sudo fuser /dev/ttyUSB0    # 점유 PID 확인
sudo kill <PID>             # 해당 프로세스 종료
```
