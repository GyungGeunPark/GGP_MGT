# Option B: 2× AA 건전지 무선 레이저 거리측정 시스템 조립 가이드 v3

> JRT U81 + ESP32-C3 Super Mini + Pololu S7V8F3 Buck-Boost  
> **v3 변경**: AO3401 소프트파워스위치 완전 제거 → AA 건전지 홀더 내장 ON/OFF 스위치 사용

---

## v3 변경 요약

| 항목 | v2 (이전) | v3 (현재) |
|------|-----------|-----------|
| 전원 스위치 | AO3401 P-ch MOSFET + 슬라이드 SW | **AA 홀더 내장 ON/OFF 스위치** |
| 제거 부품 | — | AO3401, 10kΩ, 100kΩ, 택트SW, 슬라이드SW |
| 기판 복잡도 | 중간 | **낮음** |
| 납땜 포인트 | 多 | **감소** |
| 신뢰성 | 양호 | **향상** |

**AO3401이 필요 없는 이유**: 이 시스템은 사람이 직접 켜고 끄는 용도이므로 소프트웨어 제어 전원 스위치가 불필요합니다. 건전지 홀더에 내장된 ON/OFF 스위치만으로 충분합니다.

## 2. 회로 구성

### 2.1 전원 경로

```
[AA 건전지 × 2]
  직렬 연결 → 3.0V (신품) ~ 1.8V (방전)
       │
  [홀더 내장 ON/OFF 스위치]  ← 이것만으로 전원 제어
       │
  빨간선 (+) ──────────────────────────> Pololu S7V8F3 VIN
  검은선 (─) ──────────────────────────> Pololu S7V8F3 GND
                                                 │
                                         3.3V 고정 출력
                                                 │
                              ┌──────────────────┤
                              │                  │
                         ESP32-C3 3V3       JRT U81 VCC
```

### 2.2 전압분배기 (배터리 모니터링)

```
BAT(+) ─[R1: 220kΩ 1/2W ±1%]─┬──> ESP32 GPIO3 (ADC)
                                │
                         [R2: 220kΩ 1/2W ±1%]
                                │
                         [ADC필터: 100µF 16V 전해]  (+)→분배점, (─)→GND
                                │
                               GND
```

**계산값:**
- Vadc = Vbat × 0.5
- 신품 3.0V → Vadc = 1.50V
- 방전 1.8V → Vadc = 0.90V
- 누설전류: 3.0V ÷ 440kΩ = **6.8µA** (배터리 수명 영향 극히 미미)

### 2.3 UART 연결 (크로스 필수)

```
JRT U81 TX ──────────────────> ESP32 GPIO20 (RX)  [초록 26AWG]
ESP32 GPIO21 (TX) ───────────> JRT U81 RX          [파랑 26AWG]
```

> ⚠ **TX↔RX 크로스 연결 필수**: 동일 핀끼리 연결하면 통신 불가

### 2.4 전체 연결 요약

| 연결 출발 | 연결 도착 | 와이어 색 | 게이지 |
|-----------|-----------|-----------|--------|
| 홀더 빨간선(+) | Pololu VIN | 빨강 | 24AWG |
| 홀더 검은선(─) | Pololu GND | 검정 | 24AWG |
| Pololu VOUT | ESP32 3V3, 센서 VCC | 노랑 | 24AWG |
| Pololu GND | GND 공통 버스 | 검정 | 24AWG |
| 센서 TX | ESP32 GPIO20 (RX) | 초록 | 26AWG |
| ESP32 GPIO21 (TX) | 센서 RX | 파랑 | 26AWG |
| 전압분배 출력 | ESP32 GPIO3 | 보라 | 26AWG |
| ESP32 GPIO2 | 센서 EN | 흰색 | 26AWG (선택) |

## 3. 기판 레이아웃 (70×50mm)

### 3.1 좌표 시스템

- **열(Column)**: 1~27 (좌→우), **행(Row)**: A~S (상→하)
- **하면 작업 시**: 열 방향 좌우 반전(미러)

### 3.2 부품 배치 (상면 기준)

| 부품 | 위치 | 비고 |
|------|------|------|
| BAT+ 연결점 | 열2, 행B | 홀더 빨간선 |
| BAT─ 연결점 | 열4, 행B | 홀더 검은선 |
| Pololu S7V8F3 | 열9~13, 행B~D | VIN:B9, GND:D9, VOUT:B13, GND:D13 |
| R1 (220kΩ) | 열19, 행G~K | 수직 배치 |
| R2 (220kΩ) | 열19, 행K~N | 수직 배치, K는 분배점 |
| ADC 필터 100µF | 열21, 행K~N | (+)=K행, (─)=N행 |
| ESP32-C3 소켓 | 열5~17, 행H~P | 핀헤더 소켓(암)으로 탈착 |
| 디커플링 100µF | 열3, 행R~S | (+)=R행=VCC, (─)=S행=GND |
| 디커플링 100nF | 열6, 행R~S | 무극성, 100µF와 병렬 |
| 센서 커넥터 5핀 | 열10~14, 행S | VCC/GND/TX/RX/EN 순서 |

> ★ v3에서 **슬라이드 스위치(열6~8, 행B)** 배치가 제거됨 → 그 공간 여유 확보

### 3.3 ESP32-C3 핀 할당

| GPIO | 기능 | 연결 |
|------|------|------|
| **GPIO20** | UART0 RX | ← JRT U81 TX |
| **GPIO21** | UART0 TX | → JRT U81 RX |
| **GPIO3** | ADC1 | ← 전압분배 출력 |
| GPIO2 | 디지털 OUT | → JRT U81 EN (선택) |
| 3V3 | 전원 입력 | ← Pololu VOUT |
| GND | 접지 | ← GND 공통 버스 |
| GPIO8 | 온보드 LED | 상태 표시 |

## 4. 만능기판 조립 절차

### 4.1 준비물 확인

- [ ] 납땜 인두 (온도 조절 가능, 330~360°C)
- [ ] 납 (Sn63/Pb37 또는 무연납)
- [ ] 플럭스, 이선 (납 제거용)
- [ ] 멀티미터
- [ ] 루페 또는 확대경
- [ ] 와이어 스트리퍼, 니퍼

### 4.2 조립 순서

#### Step 1: 핀헤더 소켓 납땜 (ESP32용)

1. 암 핀헤더 소켓(9핀 × 2열)을 **열5~17, 행H~P** 위치에 삽입
2. ESP32-C3를 임시로 꽂아 정렬 확인
3. 각 핀 납땜 → ESP32 분리
4. **소켓 사용 이유**: 펌웨어 업로드 시 ESP32만 분리해 USB 연결 가능

#### Step 2: Pololu S7V8F3 장착

1. 핀헤더 또는 양면테이프+스크류 터미널로 고정
2. **VIN, GND(in), VOUT, GND(out)** 4핀 위치 확인
3. 와이어로 해당 기판 홀에 납땜

#### Step 3: 전압분배기 조립

1. **R1(220kΩ)**: 열19, 행G~K에 수직 삽입 후 납땜
2. **R2(220kΩ)**: 열19, 행K~N에 수직 삽입 (K 홀 공유 = 분배점)
3. **ADC 필터 100µF**: 열21, 행K~N에 삽입
   - **(+) 리드(긴 리드)** → 행K (분배점 방향)
   - **(─) 리드(짧은 리드)** → 행N (GND 방향)
   - 극성 반드시 확인!

#### Step 4: 디커플링 캐패시터 (센서 VCC-GND)

1. **100µF 16V**: 열3, 행R~S
   - (+) 리드 → 행R (VCC 쪽)
   - (─) 리드 → 행S (GND 쪽)
2. **100nF 모노**: 열6, 행R~S (무극성)
3. 두 캐패시터는 센서 커넥터에서 **5mm 이내** 배치

#### Step 5: 센서 커넥터 5핀 핀헤더

1. 5핀 수 핀헤더를 **열10~14, 행S**에 납땜
2. 핀 순서: VCC(10) / GND(11) / TX(12) / RX(13) / EN(14)
3. 센서 와이어를 이 핀헤더에 연결

#### Step 6: 배터리 홀더 연결점

1. 스크류 터미널(2핀) 또는 직납땜
   - BAT+ (홀더 빨간선) → 열2, 행B
   - BAT─ (홀더 검은선) → 열4, 행B
2. 스트레인 릴리프 처리 (와이어를 케이블 타이로 기판에 고정)

> ★ **v3**: 슬라이드 스위치 납땜 불필요. 홀더 내장 스위치가 BAT+ 라인을 직접 제어.

### 4.3 하면 납땜 배선 순서

배선은 **기판 하면**에서 와이어로 연결합니다.  
하면에서 작업할 때는 **좌우가 반전(미러)** 됨을 주의합니다.

```
① GND 버스 (검정 24AWG) — 가장 먼저
   BAT─, Pololu GND(in/out), ESP32 GND(좌/우), 센서 GND,
   디커플링(─), R2 하단, ADC필터(─) 모두 공통 연결

② 3.3V 버스 (노랑 24AWG)
   Pololu VOUT → ESP32 3V3 + 센서 VCC + 디커플링(+)

③ BAT+ 직결 (빨강 24AWG)
   홀더 BAT(+) → Pololu VIN  ← 스위치 없이 직결
   (ON/OFF는 홀더 내장 스위치로 제어)

④ 전압분배기 출력 (보라 26AWG)
   분배점(R1/R2 중간) → ESP32 GPIO3

⑤ UART 크로스 (초록/파랑 26AWG)
   센서 TX → GPIO20(RX)  [초록]  ← 크로스!
   GPIO21(TX) → 센서 RX  [파랑]  ← 크로스!

⑥ EN 제어선 (흰색 26AWG, 선택)
   ESP32 GPIO2 → 센서 EN
```

## 5. 전원 ON/OFF 방법

```
[홀더 내장 스위치]
  ON  위치 → 건전지 → Pololu → 3.3V 출력 → 시스템 동작
  OFF 위치 → 회로 차단 → 소비 전류 0
```

**대기 전류**: 스위치 OFF 시 완전 차단 (누설 전류 없음)  
**ON 전환 시**: Pololu S7V8F3 기동 시간 ~1ms → ESP32 부팅 ~500ms → 센서 초기화 ~300ms → 동작 시작

> **장기 보관 시**: 스위치 OFF + 건전지 홀더에서 건전지 분리 권장 (AA 건전지 누액 방지)

## 7. 테스트 절차

### 7.1 전원 테스트

```
1. 건전지 홀더에 AA 알카라인 2개 삽입
2. 홀더 내장 스위치 OFF 확인
3. 멀티미터로 Pololu VIN-GND 간 전압 측정 → 0V 확인 (스위치 OFF)
4. 스위치 ON → Pololu VIN-GND = ~3.0V 확인
5. Pololu VOUT-GND = 3.3V ±0.1V 확인  ← 반드시 이 단계 후 ESP32 연결
6. ESP32, 센서 연결
```

### 7.2 UART 통신 테스트

```cpp
// 테스트 코드 (Arduino IDE → 시리얼 모니터 115200)
HardwareSerial LaserSerial(0);
void setup() {
    Serial.begin(115200);
    LaserSerial.begin(19200, SERIAL_8N1, 20, 21);
    delay(300);
    LaserSerial.write('O');   // 레이저 ON
    delay(100);
    LaserSerial.write('D');   // 거리 측정
}
void loop() {
    if (LaserSerial.available()) {
        Serial.println(LaserSerial.readStringUntil('\n'));
    }
}
// ✅ Pass: "X.XXXm, XXXX" 형식 응답
// ❌ Fail: TX/RX 크로스 연결 재확인
```

### 7.3 무선 테스트

- **BLE**: 스마트폰 nRF Connect에서 "JRT-U81-LDS" 디바이스 검색
- **WiFi**: 시리얼 모니터에서 "WiFi 연결 완료! IP: x.x.x.x" 확인

## 8. 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 스위치 ON해도 전원 안 들어옴 | 홀더 스위치 접촉 불량 | 멀티미터로 홀더 출력 확인, 건전지 교체 |
| Pololu 출력 3.3V 아님 | 입력 전압 부족 (<2.7V) | 건전지 교체 |
| 센서 통신 없음 | TX/RX 뒤바뀜 | GPIO20↔GPIO21 크로스 재확인 |
| ADC 전압 부정확 | 저항값 오차 | 멀티미터로 분배점 전압 실측 후 보정계수 적용 |
| 전원 투입 시 ESP32 리셋 | 전류 스파이크 | 470µF 캐패시터 추가 (3.3V 버스) |
| 배터리 소모 빠름 | WiFi 상시 활성 | BLE 모드 전환 권장 |
